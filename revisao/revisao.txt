// B
public class Pedido {
    public static final int LIMITE = 10;
    public void altera () { LIMITE = 20; }
}
Resposta: Não compila: o final deixa ele constant, não podendo atribuir um novo valor ao LIMITE
Remover public void altera () { LIMITE = 20; }, ou remover o final, caso ele tenha que ser alterado

// C
public class Conversor {
    public int converte ( int valor ) { return valor * 2; }
    public double converte ( int valor ) { return valor * 2.0; }
}
Resposta: Não compila: ambos possuem a mesma assinatura, mesmo nome e parâmetros
Alterar o nome de uma, ou mudar o parâmetro
